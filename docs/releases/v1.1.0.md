# ContextOS v1.1.0 更新说明

发布日期：2026-08-28

## 本次更新重点

v1.1.0 完成 Agent OS P0 的运行时收口：Agent 模板不再只是 UI 预设，而会生成聊天运行时实际读取的项目配置。同时修复 SkillHub 异常数据导致 Skills 页面白屏的问题。

## 用户可见变化

- Skills 页面可容忍 SkillHub 的对象型作者和异常卡片字段；单条坏数据不会拖垮整个页面。
- AI 研究员、代码助手等模板会绑定实际安装后的默认 Skill，并保存项目级系统提示词。
- 项目聊天顶部会如实显示以下未就绪原因：
  - 模型未配置凭证；
  - 模型不支持工具；
  - 必需 MCP 未连接；
  - Brave 等必填 MCP 凭证缺失；
  - 必需 MCP 的工具被禁用。
- 缺少工具能力的模型仍可进行普通聊天，但不会显示为 Agent 已就绪。
- 用户显式解绑项目 Skill 后，刷新或重新进入项目不会自动恢复绑定。

## 兼容与升级

- 无需迁移本地 IndexedDB 数据。
- 旧版内置模板项目会通过窄范围兼容逻辑恢复项目系统提示词和默认 Skill。
- API Key 继续只保存在本地 localStorage，不随项目记录上传。
- 高风险和写入工具继续默认关闭，每次调用仍需用户授权。

## 验证结果

- 自动化测试：5 个测试文件、28 项测试全部通过。
- ESLint：通过。
- Vite 生产构建：通过。
- 浏览器验收：Overview、Skills、MCP 和 AI 研究员模板项目通过。
- Skills 页面浏览器控制台：0 error、0 warning。
- 两个任务节点分别经过独立 Reviewer 复核，整分支终审为 `APPROVED`。

完整技术验收记录见 [Agent OS P0 Verification](../plans/2026-08-28-agent-os-p0-verification.md)。
